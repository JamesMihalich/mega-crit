# Welcome to `mega-crit`

A sibling of the broader `mega-seg` family, `mega-crit` stands on it's own as an important tool for training and quantifying the quality of machine learning networks. `mega-crit` provides a library of ever-growing criterion that can stand alone, be composed into a validation suite, or be initialized by a unified `Criterion` API.
